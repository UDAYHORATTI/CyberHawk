# CyberHawk
Real-Time Network Threat Hunter Using ELK &amp; Snort
•	Built a fully virtualized SOC using ELK Stack and Snort IDS to simulate real-time threat detection and log analysis.
•	Executed crafted malicious PCAP files to trigger Snort alerts with custom rules, replicating real-world attack scenarios.
•	Applied manual and automated log parsing to enhance event correlation and visibility within ELK.
•	Used Windows client to simulate authentic TTPs, generating realistic logs for live threat analysis.
•	Developed through iterative testing, showcasing practical end-to-end SOC implementation with threat hunting and response.
